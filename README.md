# La Pierre Mystérieuse

Platformer éducatif pour le projet **Arts Plastiques** de la classe **5°8**.

## Jouer

Ouvre le site déployé et clique sur **Commencer l’aventure**.

- **Déplacement** : flèches ou `WASD`
- **Saut** : `Espace` / flèche haut / `W`
- Collecte les **3 fragments** de chaque niveau (3 niveaux)
- À la fin, entre ton prénom, nom et classe `5°8` pour enregistrer ton score

## Résultats

Le bouton **Voir les résultats** demande le code de classe `5°8` puis affiche le classement (stocké localement dans le navigateur).

## Technique

Site statique (HTML / CSS / Canvas JS), déployé sur Vercel.
